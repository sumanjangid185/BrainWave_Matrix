# 💰 Expense Tracker Web App

A simple and intuitive web app to **track your expenses and income** with real-time balance updates and an interactive chart.  

## 🌟 Features  
✅ **Add & Remove Transactions**  
✅ **Real-Time Balance Updates**  
✅ **Visual Income vs Expense Chart** 📊  
✅ **Transaction History**  
✅ **Toast Notifications for Actions**  

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Charting Library:** Chart.js  

## 🚀 Usage  
1️⃣ Enter a description and amount.  
2️⃣ Click **"Add Transaction"** to update balance and chart.  
3️⃣ View transaction history and delete if needed.
